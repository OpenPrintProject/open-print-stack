## Developer Certificate of Origin

Every commit must be signed off to certify that you wrote it, or otherwise
have the right to submit it under the project's license. This is the
[Developer Certificate of Origin (DCO) 1.1](https://developercertificate.org/).

Sign off by adding the `-s` flag when you commit:

```bash
git commit -s -m "Describe your change"
```

This adds a line to the commit message using your git name and email:

```
Signed-off-by: Your Name <your.email@example.com>
```

Use your real name. Pull requests containing commits without a sign-off
can't be merged.

If you forgot to sign off your most recent commit, amend it:

```bash
git commit --amend -s --no-edit
```
